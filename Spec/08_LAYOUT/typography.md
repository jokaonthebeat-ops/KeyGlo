# KeyGlo Typography

No font files are included. Use installed/system fonts.

Preferred family order:

1. Inter Display
2. Inter
3. SF Pro Display on macOS
4. Segoe UI on Windows
5. Arial

## Base-canvas sizes

- Logo: supplied image asset; do not typeset it.
- Center detected key: 34–40 px, semibold.
- Artist Fit score: 46–54 px, medium.
- Section titles: 18–20 px, semibold, uppercase.
- Primary values: 18–26 px, medium/semibold.
- Row labels: 13–15 px, regular/medium.
- Secondary descriptions: 11–13 px, regular.
- Footer/status: 11–13 px, medium with modest tracking.

Use optical alignment and stable tabular-number widths for moving values. Do not allow score changes to shift adjacent labels.
