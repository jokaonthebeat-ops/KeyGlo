# Responsive and Scaling Rules

- Design coordinate system: **1491 × 1055**.
- Default editor size: **1491 × 1055**.
- Minimum recommended size: **1044 × 739** at 70%.
- Maximum normal size: **2237 × 1583** at 150%; larger is allowed when the host permits.
- Lock the aspect ratio to 1491:1055.
- Scale the entire design uniformly. Do not reflow, stack, collapse, or move panels.
- Center the design rectangle if the host supplies extra width or height.
- Use vector/custom-painted text and analyzer content so it stays sharp. Use 2× shell/brand assets on HiDPI displays.
- Maintain a minimum 40×40 design-pixel interaction target for major controls even when decorative artwork is smaller.
